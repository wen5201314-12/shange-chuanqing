# 山歌传情 · 听见山河，遇见知音

一个以四川民歌为主题的滚动叙事音乐网站。单文件架构（`index.html` 即整站），无需构建工具，克隆即用。

**在线演示**：<https://wen5201314-12.github.io/shange-chuanqing/>

## 作品亮点

- **3D 山歌隧道**：滚动驱动的 CSS 3D 隧道叙事，逐层雾化渲染，序章随滚动穿越山谷
- **历史人声录音**：四首四川民歌均为真实人声演唱的历史录音选段，随曲目展开背后的故事
- **唱片故事卡**：每首歌配黑胶唱片封面，点击展开曲目故事与地区风物
- **乐器组合聆听**：自由组合乐器与曲目，Web Audio 实时合成（音频加载失败时自动回退为合成演示模式）
- **水墨视觉**：全程深绿主题 + 水墨背景，配套唱片封面与场景图

## 技术要点

- 单文件网页架构，无构建工具，克隆即用
- 滚动驱动的 3D 山歌隧道叙事（CSS 3D + 分层雾化渲染，含性能优化）
- Web Audio API 程序化合成民歌旋律（音频加载失败时的回退模式）
- 响应式布局，支持手机端浏览
- 性能优化：背景图 JPEG 化（减容约 88%）、去除全屏 backdrop 模糊、频谱条 transform 动画、画布像素密度上限控制
