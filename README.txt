《山歌传情 — 听见山河，遇见知音》
====================================

一个关于四川民歌的单页互动音乐网站。

在线演示
--------
https://wen5201314-12.github.io/shange-chuanqing

源码仓库（GitHub）
--------
https://github.com/wen5201314-12/shange-chuanqing


文件结构
--------
index.html      —— 网站主文件（页面、样式、全部逻辑都在这一个文件里）
audio/          —— 四首四川民歌音频（程序合成的器乐版，无版权问题）
  kangding-love-song.mp3          康定情歌（四川·康定）
  taiyang-chulai-xiyangyang.mp3   太阳出来喜洋洋（川东·啰儿调）
  huaihua-jishikai.mp3            槐花几时开（川南·高腔山歌）
  caihua-nanping.mp3              采花（川西北·南坪民歌）
assets/         —— 唱片封面图片与背景图


本地预览
--------
直接双击 index.html 即可在浏览器打开。
注意：双击方式下（file:// 协议）浏览器会拦截音频文件，
音乐会退回"合成演示模式"；要听完整录音请访问在线演示地址，
或用本地服务器打开（如 VS Code 的 Live Server 插件）。


替换为真实人声录音（可选）
--------------------------
代码无需任何改动，只要用同名文件替换 audio/ 目录下的四个 mp3：
康定情歌、太阳出来喜洋洋等真实录音可在正版音乐平台获取，
请注意使用有授权的音源。


如何参与协作（团队成员看这里）
------------------------------
1. 注册 GitHub 账号后联系仓库所有者，获得协作者邀请
2. 打开仓库页面 github.com/wen5201314-12/shange-chuanqing
3. 最简单的改法：在仓库页面按键盘上的 "." 句号键，
   会打开网页版 VS Code，直接编辑文件，改完点提交（Commit）
4. 正式一点的做法：fork / 分支 → 修改 → Pull Request → 仓库所有者审核合并
5. 代码合并进 main 分支后，线上网站会在 1-2 分钟内自动更新

技术要点（供展示介绍参考）
--------------------------
· 单文件网页架构，无构建工具，克隆即用
· 滚动驱动的 3D 山歌隧道叙事（CSS 3D + 分层雾化渲染，含性能优化）
· Web Audio API 程序化合成民歌旋律（回退模式）
· 响应式布局，支持手机端浏览
